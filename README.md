# Telegram AI Assistant

A Telegram bot project for AI-assisted conversations and automation.

## Requirements

- Python or the runtime specified by the repository
- Telegram bot token
- AI provider credentials when required by the current configuration

## Installation

```bash
git clone https://github.com/ryoaonetsuki/telegram-ai-assistant.git
cd telegram-ai-assistant
```

Install dependencies using the project's dependency file.

## Configuration

Set the Telegram token and AI provider credentials using environment variables or the configuration method expected by the source.

Never commit bot tokens or API keys.

## Run

Start the entry-point script/module defined by the repository.

## Usage

Test the bot in a private chat first. Configure group permissions only after the basic commands work correctly.

## Security

Treat all bot and AI credentials as passwords and rotate exposed credentials immediately.
